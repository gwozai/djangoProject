这个错误是由于 Django 的 `ALLOWED_HOSTS` 设置没有包含你正在访问的 IP 地址。`ALLOWED_HOSTS` 是 Django 的安全机制，指定哪些主机/域名是可以处理请求的。

### 解决方法

你需要更新 Django 项目的设置文件（通常是 `settings.py`），将 `'1.15.7.2'` 添加到 `ALLOWED_HOSTS` 列表中。

1. **找到 `settings.py` 文件**：

   在 Django 项目的根目录下找到 `settings.py` 文件。

2. **更新 `ALLOWED_HOSTS` 设置**：

   ```python
   ALLOWED_HOSTS = ['1.15.7.2', 'localhost', '127.0.0.1']
   ```

   - **`'1.15.7.2'`**：添加正在访问的 IP 地址。
   - 你也可以添加 `'*'` 来允许所有主机，但这在生产环境中不安全，通常只在开发时使用：

   ```python
   ALLOWED_HOSTS = ['*']
   ```

3. **使用环境变量配置 `ALLOWED_HOSTS`（可选）**：

   在生产环境中，通常会使用环境变量来配置 `ALLOWED_HOSTS`，这样可以更灵活地控制主机名。例如，你可以在 `settings.py` 中这样做：

   ```python
   import os

   ALLOWED_HOSTS = os.getenv('DJANGO_ALLOWED_HOSTS', 'localhost').split(',')
   ```

   然后在运行容器时传入环境变量：

   ```sh
   docker run -d -p 8000:8000 --name my-django-app \
   -e DJANGO_ALLOWED_HOSTS='1.15.7.2,localhost' \
   lihua/django-app:latest
   ```

### 重新启动 Django 应用

修改完 `ALLOWED_HOSTS` 设置后，重新构建 Docker 镜像或重新运行容器：

1. **重新构建镜像**（如果你需要把更改应用到镜像中）：

   ```sh
   docker build -t lihua/django-app:latest .
   ```

2. **重新运行容器**：

   ```sh
   docker stop my-django-app
   docker rm my-django-app
   docker run -d -p 8000:8000 --name my-django-app lihua/django-app:latest
   ```

这样，Django 应用就可以接受来自 `'1.15.7.2'` 的请求了。
